# Lamplit repository guidance

Lamplit is an independent community distribution. Keep product wording
distinct from DeepSeek ownership and keep the Partner domain terms in
`CONTEXT.md`.

## Build and verification

- The only image/release interface is the TypeScript Dagger module in
  `dagger/`. Run `dagger call -m dagger check --source .` from the repository root; it
  builds only the Core and Full application images for Linux amd64 and
  validates `compose.yaml`. Hindsight and PostgreSQL are prebuilt external
  artifacts; this public repository must not grow their Dockerfiles or Dagger
  build paths.
- `bun run check` runs fast syntax, schema, Compose, release-reference, shell,
  and Keet-asset checks. It does not replace the Dagger image check.
- `just` lists the operator recipes. `just publish-app-images vX.Y.Z` is the
  local credential-gated Core/Full fallback; it requires the stable tag to name
  the current checkout commit and passes its full SHA explicitly to Dagger.
  `just verify-memory-images` only probes the existing local memory-service
  images; `just publish-memory-images`
  is the explicit credential-gated path that loads `GHCR_USERNAME` and
  `GHCR_TOKEN` from the ignored `.env`, verifies first, and calls the existing
  push helper without building either image. Never invoke publication without
  operator credentials.
- Dagger has two cache layers: Woodpecker's trusted agent owns the persistent
  engine/cache backing, while `dagger/src/index.ts` owns narrowly named
  package-manager stores and installed-dependency caches for the three external
  plugin builds. Host `node_modules` remains excluded from source input; frozen
  installs stay authoritative, and pnpm mounts only each workspace's root
  `node_modules/.pnpm` so install recreates workspace links. Cache identities
  include the project, toolchain, runtime, and platform where relevant. Never
  cache source trees, build outputs, registry auth, or secrets.
- `dagger/sdk/` is generated by Dagger and must not be hand-edited. The
  `.build/plugins` files are generated tarballs and remain outside Git; the
  checked-in `.keep` only makes direct Docker contexts predictable.

## Runtime safety

- DSH state is `/home/lamplit/.local/state/dsh`; the Partner workspace is
  `/workspace`. Never merge these persistence boundaries or seed over a
  non-empty state volume.
- Keet runtime bytes come from an operator read-only bind at
  `/opt/keet-runtime`; identity data is writable and separate. Never commit,
  download into the repository, or add a Keet runtime asset to an image.
- Credentials belong in runtime settings, environment/secrets, or DSH
  credential storage. Examples use placeholders and must never contain real
  tokens.

## Compose and release

- Full Compose has exactly four application services and no Redis/Valkey. Keep
  PostgreSQL on the internal network with no host port and keep user-facing
  ports loopback-bound by default.
- Stable tags are supplied as `vX.Y.Z`; Dagger publishes Core `X.Y.Z` and Full
  `X.Y.Z-full`, with rolling Core `latest` and rolling Full `full`. The
  independently published memory images have their own `0.1.1` version and
  are consumed by Compose at their public `publishedDigest` values. The
  manifest also records each local source `localDigest` for pre-publication
  verification; these values may differ. There is no `full-latest` tag.
- Forgejo remains canonical and GitHub is a passive mirror. Woodpecker owns
  automated checks and stable Core/Full publication; its `ghcr_username` and
  `ghcr_token` secrets plus the trusted agent's persistent-cache Dagger runner
  are operator prerequisites documented in `README.md`. The local fallback is
  `just publish-app-images vX.Y.Z`; code must not pretend to provision or verify
  these external settings.

Lamplit-owned repository code and image assembly use Elastic License 2.0
(`Elastic-2.0`). Describe Lamplit as source-available, publicly available, and
free for compliant self-hosting; do not describe it as OSI open source. The
Elastic License hosted/managed-service restriction keeps the hosted control
plane outside this repository. Preserve upstream licenses separately in
`licenses/` and `THIRD_PARTY_NOTICES.md`; regenerate `sbom/lamplit.spdx.json`
when dependency inputs change, and keep both artifacts in released images.

Do not add `.scratch/` material to Git. Update ADRs when a product decision
changes, and keep `CONTEXT.md` implementation-free.
